# Portfólio — Davi Galiano

Site pessoal responsivo feito com HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador.

## Personalizações importantes antes de publicar
- Em `index.html`, substitua `davi.galiano@example.com` pelo seu e-mail real.
- Se desejar, adicione links de GitHub ou redes profissionais na seção Contato.
- Os visuais dos projetos são composições ilustrativas feitas em CSS; os links levam aos projetos publicados.
- Você pode editar cores no início de `style.css`, nas variáveis `--orange`, `--purple`, `--bg` e `--text`.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `style.css`: identidade visual, layout e responsividade.
- `script.js`: menu mobile, animações de entrada e botão de copiar e-mail.
